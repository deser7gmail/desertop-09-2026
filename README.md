# Каталог скриптов из Telegram-канала @desertop

Страница каталога: https://deser7gmail.github.io/desertop-09-2026/

Здесь 151 скрипт из 70 постов канала [@desertop](https://t.me/desertop): имя, размер, где именно лежит файл
(в посте, внутри архива или только упомянут в тексте), краткое описание и ссылка на пост.

Файлы:

- `index.html` — страница с поиском по названию и описанию, фильтром по типу и сортировкой. Один файл, без
  сборки и внешних зависимостей.
- `desertop_scripts.md` — тот же каталог текстом (удобно читать в GitHub и в любом редакторе).
- `desertop_scripts.csv` — для Excel: разделитель `;`, кодировка UTF-8 с BOM.

Как собрано: по экспорту канала за 30.09.2026. Архивы из постов распакованы, содержимое проверено — скрипты
внутри архивов вынесены отдельными строками. Посты с пиратскими сборками (GenP, репаки, торренты) в каталог не
попали.

Про описания: текст без пометки — из того же поста, где файл. «из tg N» — соседний пост называет скрипт по
имени. «возможно, из tg N» — соседний пост просто рассказывает про скрипт, стоит проверить. «описания нет» —
в канале файл выложен без текста.

Правообладателям: каталог — это ссылки на посты авторского канала, сами скрипты распространяются в Telegram.
Если какую-то позицию нужно убрать, напишите в [@desertop](https://t.me/desertop).
